This is the code for my third year university project.

## Installation
Steps to install and run the code:

1. Clone the repository
2. Create a conda environment using ``` conda create -n <env_name> python=3.12 -y ```
3. Acitvate your conda environment using ``` conda activate <env_name> ```
4. Install `poetry` using ``` pip install poetry ```
5. Install dependencies with ``` poetry install ```
6. Run the code by running ``` python prbx_project/main.py ``` from the project's root directory
7. (Extra) you can modify the program's configurations by editing `prbx_project/config.yaml`
